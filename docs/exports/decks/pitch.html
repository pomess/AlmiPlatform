03 — THE PRODUCT

Three primitives the buyer actually cares about.

  1. Per-client workspaces. One space per engagement. Meeting notes, variance commentary, board updates — kept in client-scoped markdown the assistant reads from but never crosses.
  2. Approve every send. Every outbound action pauses in a queue with a 5-minute countdown. Defaults are conservative. Nothing reaches your client until you tap approve.
  3. Exportable audit log. Every tool call, every approval, every send → JSONL. Exportable to PDF for any engagement-end review.

04 — WHY THIS WINS

The defensible layers are not the LLM.

DEFENSIBLE
  • Approval gate on persisted LangGraph interrupts — survives restarts; any channel can resolve.
  • Markdown-as-source-of-truth — no vector DB lock-in. Diffable, hand-editable.
  • Wikilink graph + lint — navigation and integrity in one.
  • Multi-channel queue — same DB visible from web, CLI, future surfaces.
COMMODITY

LangChain · Gemini · FastAPI · React · SQLite · Vite · Typer. Replaceable layers. The product still works if any one of them changes.

The moat is the choreography, not the components.
