## Quick Reference

- **Default workhorse:** `gemini-2.5-pro` or `gemini-pro-latest`
- **Cheap & fast:** `gemini-2.5-flash-lite` / `gemini-flash-lite-latest`
- **Cutting edge:** `gemini-3.1-pro-preview`
- **Images:** `gemini-3-pro-image-preview` (Nano Banana Pro) or `imagen-4.0-ultra-generate-001`
- **Video:** `veo-3.1-generate-preview`
- **Real-time audio:** `gemini-2.5-flash-native-audio-latest`
- **Live bidirectional:** `gemini-3.1-flash-live-preview`
- **Embeddings:** `gemini-embedding-2`

## Refreshing this list

```bash
curl -s "https://generativelanguage.googleapis.com/v1beta/models?key=$GOOGLE_API_KEY"
```

Paginate using `pageToken` from `nextPageToken` in the response.
